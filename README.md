Gestión Bancaria



Aplicación de gestión bancaria desarrollada en Java como proyecto práctico para integrar conocimientos de Programación Orientada a Objetos, JDBC, SQL y desarrollo de interfaces gráficas.



📌 Descripción



El proyecto permite gestionar clientes, cuentas y movimientos bancarios mediante una interfaz gráfica desarrollada con Java Swing y una base de datos MySQL.



La aplicación utiliza JDBC para establecer la comunicación entre Java y la base de datos y permite realizar diferentes operaciones de gestión sobre la información.



🚀 Funcionalidades



\- Registro y gestión de clientes.

\- Consulta de clientes.

\- Creación y gestión de cuentas bancarias.

\- Consulta de información de cuentas.

\- Registro y consulta de movimientos.

\- Actualización de información.

\- Eliminación de registros.

\- Manejo de errores y excepciones.

🗃️ Base de datos



La aplicación utiliza MySQL como sistema de gestión de base de datos y JDBC para la comunicación con Java.



El proyecto incluye:



\- 📄 Script SQL de la base de datos.

\- 📊 Diagrama entidad-relación.

\- 🔗 Relaciones mediante claves primarias y foráneas.



Los datos personales utilizados durante las pruebas fueron reemplazados por información ficticia antes de publicar el proyecto.



⚙️ Cómo ejecutar



1\. Tener instalado Java JDK, MySQL y NetBeans.

2\. Ejecutar el script SQL ubicado en "Database".

3\. Configurar la conexión a MySQL en las clases DAO.

4\. Abrir el proyecto en NetBeans.

5\. Ejecutar la aplicación.
